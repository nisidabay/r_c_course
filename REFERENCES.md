# References

| Book | Author | Why this |
|------|--------|----------|
| **Effective C** (2nd ed.) | Robert C. Seacord | The course's primary reference. Teaches safe C from day one — no `scanf`, no `gets`, no buffer overflows. |
| **C Programming: A Modern Approach** (2nd ed.) | K. N. King | The most thorough C textbook. Use it when you want the full story on any topic. |
| **The Linux Programming Interface** | Michael Kerrisk | The definitive guide to Linux system programming — files, processes, signals, everything. |
